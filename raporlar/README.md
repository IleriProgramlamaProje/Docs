# Raporlar

- `ogretmen_secimi.md`: öğretmen model denemesi (LM Studio, 2 tur) · hız ölçümü sonuçları da buraya eklenecek
- `donem-{N}-yapay-zeka.md`, `donem-{N}-oyun.md`: dönem raporları (dönemin son pazarı, giden başkan)
- `denge_testi.md` (4. hafta), `oyun_testi.md` (7. hafta)

## Dönem raporu şablonu

```markdown
# Dönem N · Yapay Zekâ · Başkan: … · Yardımcı: …
## Ne yapıldı (dosya yollarıyla)
## Ne yarım kaldı, neden
## Nasıl çalıştırılır (komutlar, Colab defterleri)
## Büyük dosyalar nerede (Drive / Hugging Face)
## Bilinen sorunlar
## Sayılar (üretilen hikâye, eğitim kaybı, test sonuçları…)
## Yeni gelen için ilk 3 adım
```

Göndermeden önce `yol_haritasi.md` 3.2'deki "devredilebilir durum" listesini kontrol et.
